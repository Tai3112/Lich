Hướng Dẫn Deploy Lên GitHub Pages & Lấy Discord Webhook

1 Cách tạo Discord Webhook nhận thông báo

  1. Mở ứng dụng Discord trên máy tính hoặc trình duyệt.
  2. Vào Server Settings (Cài đặt máy chủ) hoặc click chuột phải vào Kênh (Channel) bạn muốn nhận thông báo -> chọn Edit Channel.
  3. Chọn mục Integrations (Tích hợp) -> Click vào Webhooks.
  4. Bấm New Webhook, đặt tên cho Bot (VD: Lịch Reminder Bot) và chọn Channel gửi đến.
  5. Nhấn Copy Webhook URL.
  6. Quay lại ứng dụng này, sang tab Cấu Hình Nhắc Nhở và dán link vào ô Discord Webhook URL -> Bấm Lưu.

2 Cách đưa ứng dụng này lên GitHub Pages miễn phí

Bước 2.1: Đặt tên tệp file HTML này là index.html.

Bước 2.2: Đăng nhập vào trang GitHub.com và bấm New Repository.

Bước 2.3: Đặt tên Repo (VD: my-event-scheduler), để chế độ Public, sau đó nhấn Create Repository.

Bước 2.4: Tải file index.html lên Repo vừa tạo (Bấm uploading an existing file -> Chọn file -> Commit changes).

Bước 2.5: Kích hoạt GitHub Pages:

  • Vào mục Settings của Repository đó.
  • Tìm mục Pages ở cột menu bên trái.
  • Tại phần Build and deployment -> Branch: Chọn branch main (hoặc master) và thư mục /(root).
  • Bấm Save. Sau khoảng 1-2 phút, GitHub sẽ cấp cho bạn đường link Web dạng: https://<your-username>.github.io/my-event-scheduler/.
